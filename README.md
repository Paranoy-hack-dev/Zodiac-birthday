# Memento Mori - Compteur de Temps Restant

Une application web sombre et esthétique avec une pierre tombale, qui affiche le temps restant avant la mort sur une base d'espérance de vie moyenne.

## Fonctionnalités

- Saisie de la date de naissance
- Choix de la base : moyenne mondiale (~74 ans), homme (~71), femme (~76), ou personnalisé
- Affichage en direct du temps restant :
  - Jours totaux (grand nombre gravé sur la pierre)
  - Années, mois, heures
  - Nombre de lunes (cycles lunaires de ~29.53 jours)
  - Compteur heures:minutes:secondes en temps réel
- Thème sombre, brumeux, pierre tombale en CSS
- Sauvegarde locale (localStorage)
- Interface en français

## Utilisation

Ouvre simplement `index.html` dans un navigateur.

Ou héberge-le sur GitHub Pages, Netlify, etc.

## Données

Basé sur les estimations ONU pour 2026 :
- Moyenne mondiale : ~73.8 ans
- Hommes : ~71.2 ans
- Femmes : ~76.4 ans

## Personnalisation

Tu peux modifier les valeurs dans le `<select>` de `index.html` ou dans le code JS.
